Perguntas Frequentes

O que é código ZPL?

ZPL (Zebra Programming Language) é a linguagem desenvolvida pela Zebra Technologies para criar etiquetas em impressoras térmicas. O código começa com ^XA e termina com ^XZ.

Posso converter múltiplas etiquetas?

Sim! Você pode enviar um arquivo ZIP com vários arquivos ZPL ou separar múltiplos códigos com quebras de linha no modo texto.

Os dados são enviados para algum servidor?

Não. Este conversor funciona 100% no seu navegador. Seus dados ZPL não saem do seu computador. Utilizamos a API Labelary pública apenas para renderização.
